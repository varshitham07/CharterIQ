# CharterIQ Product Spec v2

## North-star user
Bulk-cargo procurement / chartering manager planning future overseas cargo into India's East Coast.

## Must demonstrate

- future cargo planning
- uncertainty-aware freight forecast
- vessel feasibility
- port feasibility
- contract coverage comparison
- what-if disruption simulation
- explainability + data lineage

## Secondary

- alternative port analysis
- idle/deadheading risk placeholder
- future live-feed adapters
- retraining loop

## UX principles

- dense but calm operator console
- navy/charcoal base + precise cyan accents
- no fake glassmorphism
- no “AI magic” without reasons
- numbers paired with assumptions/source status
- one shared scenario state across modules

## Product vocabulary

Prefer:
- decision landscape
- market exposure
- coverage
- feasibility
- scenario
- uncertainty
- resilience

Avoid:
- guaranteed savings
- perfect forecast
- autonomous chartering
